USC Platform — 24-Microservice Rust Backend
Clean Architecture · gRPC · Event-driven · Blockchain & Wallet

Hệ sinh thái backend quy mô lớn gồm 24 microservice viết bằng Rust (Gateway, Auth, User, Blockchain Core, Wallet, Social, Commerce, AI, Video, Search, Recommendation, Advertising, Jobs Grab, World/Metaverse...), giao tiếp qua gRPC, kiến trúc Clean Architecture (Porto Pattern) đồng nhất, phục vụ cho các app Flutter (mobile) và Next.js (web) trong hệ thống APPS-W.

  • Xây dựng service theo Clean Architecture (api/grpc → application → infrastructure), chuẩn hoá proto (`oneof result`, UUID v7, timestamp), tách domain model khỏi proto để dễ bảo trì.
  • Làm việc với hạ tầng dữ liệu đa dạng: ScyllaDB (primary DB), Redis Cluster (cache/session), ClickHouse (OLAP/analytics), Qdrant (vector embeddings cho AI service), InfluxDB (metrics timeseries).
  • Triển khai giao tiếp bất đồng bộ, event-driven giữa các service qua Kafka (KRaft mode, 3 brokers) cho Notification, Analytics, Recommendation.
  • Tham gia các service nghiệp vụ trọng yếu: Blockchain Core (consensus, transactions), Wallet (balances, transfers), Jobs Grab (marketplace, matching), AI (embeddings, inference, personalization).
  • Đảm bảo chất lượng qua `cargo fmt` → `cargo clippy` → `cargo test` (unit + integration + E2E) → `cargo build --release`; đóng gói Docker/Kubernetes.
